# frontend

React + Vite frontend for FlowDoc Agent Studio.

## Features

- A4 `react-konva` preview canvas (`595x842`)
- Agent command panel (Perplexity-style prompt input)
- Toolbar (alignment, delete selected, watermark, export)
- Image generation panel (generate, insert into canvas, download)

## Run locally

```bash
cd frontend
npm install
npm run dev
```
